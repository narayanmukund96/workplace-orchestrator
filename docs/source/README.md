# Workspace Orchestrator - Product Documentation Pack

This folder contains the core V1 product, technical, governance, and delivery documentation for a Windows-first local workspace orchestrator.

## V1 Scope
- Windows only
- Local-only application
- Multiple editable workspaces
- Applications only in V1
- Any installed application can be added
- Smart launch sequencing with optional timed/hybrid overrides
- Live detection of application running/closed state
- Individual app start/stop plus workspace-level stop
- No cloud account, sync, telemetry, import/export, or automatic updates in V1
- Lightweight operation is a core product requirement
