# Future Backlog

These items are intentionally deferred and should not expand V1 scope without an explicit decision.

- URLs and browser tabs
- Folders and files
- Scripts/actions
- Window layout restoration
- Multi-monitor placement
- Workspace import/export
- Cloud sync
- Cross-device profiles
- Shared/team workspaces
- Automatic updates
- Code signing and updater pipeline
- Machine-learning-based sequencing
- Historical launch-time learning
- App startup prediction
- Recommended workspace optimization
- Selective app suspend/resume
- Close/background-process optimization before launch
- macOS support
- Linux support
- Remote launch/control

## Product Direction Hypothesis
The product may evolve from a launcher into a workload preparation layer:

`Task intent -> prepare machine -> launch required environment -> maintain live workspace state`

This should remain a future direction rather than a V1 requirement.
